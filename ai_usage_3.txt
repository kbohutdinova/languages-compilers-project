## 3. Task 1: Language feature — Loops

**What I used from AI:**
AI helped generate the implementation of while and for loops, including changes to parsing, semantic checking, and LLVM IR generation.
It also helped create valid and invalid test cases.

**What I changed:**
I integrated the changes into my project, installed the required dependencies, and tested the implementation.
I also used the new loops in my interactive game.

**What I understood:**
A while loop repeats while its condition is true. A for loop goes through an integer range.
In LLVM IR, loops use basic blocks and branch instructions. A back edge returns execution to the loop condition or iteration step.

## 4. Task 2: Optimizer

**What I used from AI:**

AI helped implement three optimization transformations:

- Removal of unused variables
- Removal of unused functions
- Function inlining
AI also helped prepare tests for these transformations.

**What I changed:**

I integrated the optimizer into my project and ran the automated tests to check that optimization did not change the program output.

**What I understood:**

The optimizer works on the checked AST before LLVM IR generation.
Unused code can be removed when doing so does not change program behavior.
Inlining replaces a function call with its body. This can remove the need for a separate function call, but the optimizer must preserve the original behavior.
